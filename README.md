# K9 RAFAC Camp Companion — Camp Version 1

Camp-ready prototype for RAF Leeming, 22–28 August 2026.

- Cadets: 001–068
- Flights: A–D
- K9 uses cadet numbers only
- Names are deliberately excluded
- Sports information is intentionally left for later
- Missing information is marked TBC

The programme data is embedded in `index.html` so this version works without a server.
